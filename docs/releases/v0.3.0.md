# Weirling v0.3.0 (2026-10-25)

ReadPrism is now **Weirling**, with hosted plans and the North Star metrics.

## Before you upgrade

- [ ] Read [ReadPrism is now Weirling](../UPGRADING.md#readprism-is-now-weirling-v030):
      keep your install folder's name (or set `COMPOSE_PROJECT_NAME=readprism`),
      because Docker volume names come from it.
- [ ] Rename the email settings: `ZOHO_*` is now `SMTP_*` and the old names
      are not read ([details](../UPGRADING.md#readprism-is-now-weirling-v030)).
- [ ] Migrations 0039 to 0047 run on start; none drops data.

## Highlights

- Renamed to Weirling; domain weirling.com (#340).
- Hosted plans: Reader and Pro, a 30-day trial with Pro features, no free hosted
  tier (#172, #341); Pro-only features (#246).
- First-party product metrics and the owner dashboard at `/admin/metrics` (#131).
- Readers can bring their own LLM key on hosted (#255).

## Fixes

- Digests are marked opened again, so win-back emails no longer reach active
  readers (#131).
- gpt-oss summaries no longer run out of tokens; long provider rate-limit waits
  no longer stall workers (#225).

## Operators

- `WEIRLING_VERSION` pins images (`READPRISM_VERSION` still read).
- Email: `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD` replace the
  `ZOHO_*` settings; `FROM_EMAIL` is now honoured; new `FROM_NAME`,
  `REPLY_TO_EMAIL`, `SUPPORT_EMAIL`; port 465 works. Every email now carries
  `Date` and `Message-ID` headers, which spam filters expect.
- Railway and other hosts: a plain `postgres://` `DATABASE_URL` works.
- New settings: `PRODUCT_METRICS`, `HOSTED_PAUSED_DELETE_DAYS`,
  `HOSTED_DELETE_REMINDER_DAYS`, `HOSTED_PRO_MAX_POLL_MINUTES`,
  `LLM_REASONING_EFFORT`, `LLM_MAX_RETRY_WAIT_SECONDS`.
- Migrations: 0039 quota overrides, 0040 trial email stage, 0041 users' LLM keys,
  0042 takedown list, 0043 terms consent, 0044 deletion reminder,
  0045 product events, 0046 interest embedding model, 0047 SMTP setting names.
