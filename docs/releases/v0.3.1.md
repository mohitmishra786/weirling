# Weirling v0.3.1 (2026-10-25)

Fixes the published backend images: in v0.3.0 the full and lite tags held
the same amd64 image, the lite one.

## Before you upgrade

No action needed beyond the usual [upgrade steps](../UPGRADING.md). If you
ran the v0.3.0 `weirling-backend` image on amd64, you were on the lite build
(hash embeddings); items it embedded keep those vectors until they age out.

## Fixes

- `weirling-backend:0.3.1` is the full image and `0.3.1-lite` the lite one,
  on both amd64 and arm64. The publish job now refuses to tag anything but
  exactly one image per architecture.
- A clear "DATABASE_URL is empty" error instead of a SQLAlchemy traceback.

## Operators

- The Railway and Vercel guide is corrected: connection variables go on each
  service, `DATABASE_URL_PRIVATE` for Postgres, and the api listens on
  `0.0.0.0`.
