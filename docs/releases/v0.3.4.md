# Weirling v0.3.4 (2026-10-26)

Claude as the first summary provider with Groq behind it, starter packs
that don't overlap, feed discovery for blogs in a sub-folder, and a reader
that fits the screen.

## Before you upgrade

No action needed beyond the usual [upgrade steps](../UPGRADING.md).
Migration `0048` runs on start: it removes HTML left in stored extract
summaries (LLM summaries are not touched).

Optional: set `ANTHROPIC_API_KEY` to have Claude (`claude-haiku-5-5` by
default) answer first, with your `LLM_*` provider as the fallback
([configuration](../CONFIGURATION.md#summaries-llm)).

## Summaries

- Providers are tried in order: Claude when `ANTHROPIC_API_KEY` is set, then
  `LLM_*`, then the OpenAI fallback, then an extract. A rejected key, an
  empty credit balance or a rate limit benches a provider for a while, so
  the next one answers at once instead of each article waiting on a failure.
- A Groq daily cap (`429` with a long `Retry-After`) now pauses Groq until
  then, instead of asking again for every article.
- Extract summaries showed raw markup for some feeds (`<p>Article URL: <a
  href=…`). They are plain text now, and existing ones are cleaned.
- Hacker News and Lobsters entries hold no article, only links. They now
  read "Discussion: 37 points, 13 comments on Hacker News" with a link, and
  are not sent to the model.

## Onboarding and starter packs

- Starter packs were rebuilt: 25 packs, 268 feeds, each feed in exactly one
  pack and every feed checked live. 43 dead, blocked, stale or mislabelled
  feeds were replaced (one pack listed the same feed three times; "Stonebraker
  Blog" pointed at Atlassian's developer blog). A test fails if a feed is
  ever added to two packs.
- New pack: Backend & Distributed Systems (Marc Brooker, Martin Kleppmann,
  Werner Vogels, aphyr, Murat Demirbas and others).
- The model now picks the packs for your interests (cached, 5 s limit,
  taxonomy as the fallback). Word matching had suggested the UI design pack
  for "system design".
- Suggested topics are short labels ("Consensus algorithms"), not sentences.
- The pack picker has a search box over pack names, descriptions and the
  sources inside each pack, and each pack says what it covers.

## Sources

- A blog in a sub-folder (`user.github.io/Blog/`) is found from its page
  URL: discovery tries the folder before the site root and follows feed
  links in the page body, not only `<link rel="alternate">`.
- `substack.com/@name` follows `name.substack.com`; other `substack.com`
  links say to use the publication's address instead of following a feed
  that doesn't exist.
- Adding a creator's blog uses the same checked discovery as adding a source.
- Feeds up to 8 MB are accepted (`FEED_MAX_BYTES`); danluu.com's 6.6 MB feed
  was rejected.

## Reader and layout

- On laptops the reader shows the article at a readable width with a side
  panel: summary, progress and time left, text size and surface, and the
  link to the original. Phones keep one column.
- Long URLs, tables and embeds no longer widen the page on phones.
- Source cards: on phones, Pause and Remove sit under the details, so a long
  name or error can't push them off screen.

## Operations

- Workers and beat log JSON to stdout like the API, so a platform's error
  view shows only errors (Celery's INFO lines went to stderr).
- Database connections are recycled every 5 minutes and time out after
  10 s; Redis and the Celery broker use keepalives and health checks. A
  connection dropped while idle no longer stalls a request.
