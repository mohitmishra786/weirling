# Weirling v0.3.2 (2026-10-25)

Email can now go out through Resend's HTTPS API, for hosts that block SMTP.

## Before you upgrade

No action needed beyond the usual [upgrade steps](../UPGRADING.md). SMTP
keeps working as before; Resend is used only when `RESEND_API_KEY` is set.

## Highlights

- Send email through Resend (`RESEND_API_KEY`, `EMAIL_PROVIDER=auto|smtp|resend`).
  Network errors, 429 and 5xx are retried with backoff; sign-in and
  confirmation links carry an idempotency key, so a retry never sends one
  twice.

## Fixes

- On hosts that block SMTP (Railway Hobby), sign-up and "Resend the link"
  no longer wait 30 seconds on a connection that can't succeed, once Resend
  is configured.

## Operators

- New settings: `EMAIL_PROVIDER` (default `auto`), `RESEND_API_KEY` (a
  sending-only key; `FROM_EMAIL` must be on a domain verified in Resend).
- The setup screen's email test sends through Resend when it is active.
